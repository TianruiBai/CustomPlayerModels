# Customizable Player Models  

Create a custom Minecraft avatar with the built-in 3D editor. Design your own player model, animate it, and share it with others.

## Features  

- **3D Model Editor** — Build your avatar from scratch with cubes, meshes, and textures  
- **Custom Animations** — Create walking, sneaking, swimming, flying, and custom gesture animations  
- **Server Model System** *(0.6.26b+)* — Upload models directly to CPM servers with AES-256-GCM encryption  
- **My Models Browser** — Browse local, server-stored, and Paste-site models in-game  
- **Export & Share** — Export to `.cpmmodel` files, upload to servers, or publish on the Paste site  
- **Copy Protection** — UUID-locked and cloneable model options  
- **Multi-Platform** — Works on NeoForge, Forge, Fabric, and Bukkit/Paper
